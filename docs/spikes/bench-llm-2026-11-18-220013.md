## Measurement notes

- TTFB is the time from the HTTP request to the first SSE chunk with non-empty `delta.content`.
- tokens/s ≈ estimated tokens divided by the generation window (`total_ms - ttfb_ms`).
- Token estimate: whitespace-split words for `en`/`de`; for `ja`/`zh` characters/1.7 (CJK tokenizers emit roughly 1.7 characters per token — this is an approximation, not a tokenizer count).
- Adherence is a heuristic: `ja` needs hiragana/katakana, `zh` needs CJK without kana, `de` needs ä/ö/ü/ß or two German stopwords, `en` needs ≥90% ASCII without CJK.
