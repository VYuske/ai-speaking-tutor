## Notes

- Adherence is a script heuristic, not a language detector: `ja` needs kana, `zh` needs Han characters and no kana, `de` needs ä/ö/ü/ß or two German stopwords, `en` needs ≥90% ASCII and no CJK. It is shared with `scripts/bench_llm.py`.
- p50 is `statistics.median` over the successful turns (for an even count it averages the two middle values), measured around the whole streamed reply.
- Scripted turns are keyed by scenario id (`SCRIPTED_TURNS`), so the learner line always fits the role the model is playing; a script that fights the scenario produces a refusal, not language signal.
- Warm-up: before the measured turns, each language sends one short in-character call whose reply and latency are discarded. The cold start of the model (~4.3 s on Ollama) therefore stays out of the p50, and `## Per-turn detail` lists the measured turns only.
- `JSON valid` counts evaluations where `chat_json` returned a parseable object that `normalize()` accepted; `Corrections` sums `normalize()` output over the scripted turns.
- Harness vs. product: no STT/TTS, empty learner memory, a fixed level, a fixed 2-turn script and one evaluation call per turn.
- The harness never prints the API key and builds no shell command.
- Write policy: a real run writes `<out-dir>/eval-prompts-<date>.md` and refuses to overwrite without `--force`. `--dry-run` prints the report to stdout and writes nothing unless `--force` is given together with a temporary `--out-dir`.
